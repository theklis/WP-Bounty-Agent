# Bounty and program intelligence

Read [Wordfence program intelligence](wordfence/README.md) only when target selection, scope, submission, or disclosure depends on current rules. The dated snapshot is a starting point, never a final eligibility decision; recheck official sources for the target and researcher tier. Use the [intelligence convention](../../docs/current-intelligence.md) for freshness and the [record template](../../templates/intelligence-record.md) for new sourced facts. Historical vulnerability records do not establish current bounty scope. See the [knowledge index](../README.md).
