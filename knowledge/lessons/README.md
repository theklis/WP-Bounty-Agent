# Curated lessons

Store **CURATED** operational lessons from human outcomes: better research questions, prioritization, falsification, chain tracing, coverage, and workflow decisions. Include corrections and useful rejected paths; no vulnerability is required. Each lesson records origin, evidence basis, applicability, counterexamples, and what not to generalize. Use the [lesson template](../../templates/lesson.md) and [learning workflow](../../docs/learning-workflow.md); keep **PROPOSED** and **REJECTED** drafts in ignored `research/lessons/`.

Load only lessons relevant to the current feature, workflow, or selected playbook. A lesson may propose a methodology or playbook change, but does not authorize editing those documents. Target-specific narratives belong in [cases](../cases/README.md); generalized security path patterns belong in [patterns](../patterns/README.md). See the [knowledge index](../README.md).
