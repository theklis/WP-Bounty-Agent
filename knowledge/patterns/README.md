# Research patterns

Store **CURATED**, bounded research patterns that transfer across applicable architectures. Each states when it is relevant, the actor/object or state boundary to trace, the question or proof required, likely blockers and counterexamples, supporting outcomes, and why generalization is justified. A pattern is a testable lead, not a declaration that every occurrence is vulnerable. Use a reviewed [lesson proposal](../../templates/lesson.md) to establish provenance before promotion; a [case](../cases/README.md) can preserve the original path without duplicating it here.

Select patterns by the target's architecture, features, and chosen playbooks. Detailed specialist procedures belong in [playbooks](../../playbooks/README.md) and require their own change approval. See [the learning workflow](../../docs/learning-workflow.md) and [knowledge index](../README.md). No curated pattern is present yet.
