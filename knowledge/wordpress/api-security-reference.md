# Security-relevant API quick reference

Use this to choose a topic document, not to infer a finding from a function name. The “does not prove” column is an audit boundary. API behavior must be checked against the target's installed WordPress/WooCommerce/PHP versions; references were consulted **2026-09-19**.

| API / hook | What it establishes | Does not prove; trace next |
| --- | --- | --- |
| [`add_action()` / `add_filter()`](https://developer.wordpress.org/plugins/hooks/) | Callback registration for an event or data filter | External reachability; follow firing path in [request model](request-model.md). |
| [`is_user_logged_in()`](https://developer.wordpress.org/reference/functions/is_user_logged_in/) | Current visitor has a WordPress user | Permission for action/object; [identity](identity-and-capabilities.md). |
| [`wp_get_current_user()`](https://developer.wordpress.org/reference/functions/wp_get_current_user/) | Current user object | That any role/capability or relationship applies; [identity](identity-and-capabilities.md). |
| [`current_user_can()`](https://developer.wordpress.org/reference/functions/current_user_can/) / [`user_can()`](https://developer.wordpress.org/reference/functions/user_can/) | Effective capability for a user, with object arguments where applicable | Plugin-specific ownership or correct object after substitution; [ownership](ownership-and-plugin-models.md). |
| [`map_meta_cap()`](https://developer.wordpress.org/reference/functions/map_meta_cap/) | Maps a meta capability using context | That caller supplied the right object or that plugin rules are covered; [identity](identity-and-capabilities.md). |
| [`wp_create_nonce()` / `wp_verify_nonce()`](https://developer.wordpress.org/apis/security/nonces/) | Time/action/session-related request token and its verification | Authentication, authorization, ownership, secrecy, single use; [nonces](nonces-and-tokens.md). |
| [`check_admin_referer()`](https://developer.wordpress.org/apis/security/nonces/) / [`check_ajax_referer()`](https://developer.wordpress.org/reference/functions/check_ajax_referer/) | Request-integrity check when used correctly | Permission to act; verify failure handling in [nonces](nonces-and-tokens.md). |
| [`wp_ajax_*` / `wp_ajax_nopriv_*`](https://developer.wordpress.org/reference/hooks/wp_ajax_action/) | AJAX action dispatch by login branch | Role-specific or object permission; [AJAX](ajax-and-admin-post.md). |
| [`admin_post_*` / `admin_post_nopriv_*`](https://developer.wordpress.org/reference/hooks/admin_post_action/) | Form/action dispatch by login branch | Administrator-only reachability; [admin-post](ajax-and-admin-post.md). |
| [`register_rest_route()`](https://developer.wordpress.org/reference/functions/register_rest_route/) | Route, method, callback, permission and argument declarations | Safety of public route or adequacy of broad permission; [REST](rest-api.md). |
| [`sanitize_text_field()`](https://developer.wordpress.org/apis/security/sanitizing/) / [`sanitize_key()`](https://developer.wordpress.org/apis/security/sanitizing/) / [`sanitize_email()`](https://developer.wordpress.org/apis/security/sanitizing/) | Input transformation for certain value types | Safe use in every sink or permission; [data handling](data-and-storage.md). |
| [`absint()`](https://developer.wordpress.org/reference/functions/absint/) / [`intval()`](https://www.php.net/manual/en/function.intval.php) | Numeric conversion | Valid object, ownership, or allowed range; [data handling](data-and-storage.md). |
| [`esc_html()` / `esc_attr()` / `esc_url()`](https://developer.wordpress.org/apis/security/escaping/) | Escaping for specific HTML/URL output contexts | Safety in another parser or later transformation; [data handling](data-and-storage.md). |
| [`wp_kses()` / `wp_kses_post()`](https://developer.wordpress.org/apis/security/escaping/) | Restricted HTML allowance | Safety in JavaScript, SQL, or arbitrary attributes; [data handling](data-and-storage.md). |
| [`$wpdb->prepare()`](https://developer.wordpress.org/reference/classes/wpdb/prepare/) | Escapes/binds supported placeholders | Safety of arbitrary SQL fragments or authorization; [database](data-and-storage.md). |
| [`esc_sql()`](https://developer.wordpress.org/reference/functions/esc_sql/) | Escapes SQL data fragments | A prepared query or safe identifier selection; [database](data-and-storage.md). |
| [`update_option()`](https://developer.wordpress.org/reference/functions/update_option/) / [`update_site_option()`](https://developer.wordpress.org/apis/options/) | Persists site or network configuration | Caller permission or future safe use; [persistent state](data-and-storage.md). |
| [`update_post_meta()`](https://developer.wordpress.org/reference/functions/update_post_meta/) / user/term meta | Persists object-associated data | Object ownership or safe later consumption; [persistent state](data-and-storage.md). |
| [`maybe_unserialize()`](https://developer.wordpress.org/reference/functions/maybe_unserialize/) | Decodes a serialized value when detected | That bytes are trusted or no object is instantiated; [serialization](data-and-storage.md). |
| [`wp_insert_user()`](https://developer.wordpress.org/reference/functions/wp_insert_user/) | Creates/updates a user from supplied fields | That caller may select role or target user; [accounts](identity-and-capabilities.md). |
| [`media_handle_upload()`](https://developer.wordpress.org/reference/functions/media_handle_upload/) / [`wp_check_filetype_and_ext()`](https://developer.wordpress.org/reference/functions/wp_check_filetype_and_ext/) | Core upload/type handling in its call context | Caller authorization, safe final path, or execution impact; [files](files-and-network.md). |
| [`WP_Filesystem()`](https://developer.wordpress.org/reference/functions/wp_filesystem/) | Initializes a filesystem transport | Permission for the web caller to choose a path or content; [files](files-and-network.md). |
| [`wp_remote_post()`](https://developer.wordpress.org/reference/functions/wp_remote_post/) / [`wp_safe_remote_get()`](https://developer.wordpress.org/reference/functions/wp_safe_remote_get/) | Outbound HTTP; safe variant rejects unsafe URLs | SSRF exploitability or full redirect/credential safety; [network](files-and-network.md). |
| [`wp_redirect()` / `wp_safe_redirect()`](https://developer.wordpress.org/reference/functions/wp_safe_redirect/) | Redirect; safe variant checks allowed hosts | Impact or automatic termination; [redirects](files-and-network.md). |
| [`wp_schedule_event()`](https://developer.wordpress.org/reference/functions/wp_schedule_event/) | Schedules a hook with arguments | Trustworthiness of stored args or runtime identity; [deferred work](background-and-rendering.md). |
| [`add_shortcode()`](https://developer.wordpress.org/reference/functions/add_shortcode/) / [`register_block_type()`](https://developer.wordpress.org/reference/functions/register_block_type/) | Registers rendering callbacks | That users can reach them or output is safe; [rendering](background-and-rendering.md). |

WooCommerce order CRUD, HPOS, order keys, and webhook semantics are extension/version-sensitive; start with [WooCommerce](woocommerce.md). Each call may be filtered or wrapped by a plugin, so inspect the actual target path before assigning a security property.
