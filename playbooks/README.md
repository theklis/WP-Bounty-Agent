# Specialist playbooks

**Future work.** This is the on-demand index for focused methods. Add a topic document only when it contains a tested, specific procedure with preconditions, evidence requirements, counterexamples, and links to primary references. Keep the shared finding and confidence rules in [docs](../docs/README.md), not duplicated in each playbook.

Planned areas: authorization, authentication, filesystem, injections, client-side issues, state and tokens, business logic, REST, AJAX, and chaining. This list is extensible; plugin-specific functionality can require a new method. None of these playbooks is implemented in Milestone 1.
