# Local research workspace

All contents under `research/` except this README are ignored by Git. Create records locally in these directories as needed:

| Directory | Local contents |
| --- | --- |
| `targets/` | Supplied source trees, archives, provenance, and target selection notes |
| `audits/` | Architecture maps, surface inventories, traces, and dated [research journals](../templates/journal.md) |
| `findings/` | Working records based on the [finding template](../templates/finding.md) |
| `benchmarks/` | Blind runs, withheld ground truth, and comparisons kept separate |
| `lessons/` | Raw researcher feedback and proposed lessons before curation |

The directory names are a convention, not an implemented workflow. Keep private data, raw traffic, proof artifacts, and generated output here or in another approved local location. Only promote sanitized, sourced material deliberately into [`knowledge/`](../knowledge/README.md) under the [repository policy](../docs/repository-policy.md). Do not force-add an entire target directory.
