# Local research workspace

All contents under `research/` except this README are ignored by Git. Create records locally in these directories as needed:

| Directory | Local contents |
| --- | --- |
| `targets/` | Supplied source trees, archives, provenance, and target selection notes |
| `audits/` | Per-audit `audit.md` records, optional extracted source, indexes, artifacts, notes, and dated [research journals](../templates/journal.md) |
| `findings/` | Working [finding records](../templates/finding.md) and [validation plans](../templates/validation-plan.md) linked from an audit |
| `benchmarks/` | Blind runs, withheld ground truth, and comparisons kept separate |
| `lessons/` | Raw researcher results, corrections, private evidence, and [proposed lessons](../templates/lesson.md) before review and curation |

For local source intake and per-audit layout, use the [Source Audit workflow](../docs/source-audit/README.md). Keep private data, raw traffic, proof artifacts, and generated output here or in another approved local location. Only promote sanitized, sourced material deliberately into [`knowledge/`](../knowledge/README.md) under the [repository policy](../docs/repository-policy.md). Do not force-add an entire target directory.
